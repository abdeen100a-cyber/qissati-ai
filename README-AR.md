# قصتي AI — نسخة جاهزة للنشر على Cloudflare Pages

## ماذا تعمل؟
- واجهة عربية لتقسيم القصة إلى مشاهد.
- نقطة API آمنة على الخادم تستخدم fal.ai Vidu Image-to-Video.
- مفتاح FAL_KEY يبقى سرياً في إعدادات Cloudflare ولا يوضع داخل الصفحة.

## النشر (مرة واحدة)
1. ارفع محتويات هذا المجلد إلى مستودع GitHub.
2. في Cloudflare Pages اختر Create project ثم Connect to Git واختر المستودع.
3. Build command: `npm install` (أو اتركه فارغاً إن لم يطلبه).
4. بعد النشر افتح Settings > Variables and Secrets وأضف متغيراً سرياً اسمه `FAL_KEY` وقيمته المفتاح الجديد من fal.ai.
5. أعد النشر.

ملاحظة: المفتاح الذي نُشر في المحادثة سابقاً يجب إلغاؤه، واستخدم مفتاحاً جديداً فقط. لا تضع المفتاح في ملفات الموقع أو GitHub.
